# صفحة تسعير المشرف — دليل الإعداد

صفحة داخلية على المسار **`/admin/pricing`** يستخدمها مشرف التسعير لتسعير
الفلل والأدوار والشقق والمكاتب، وإخراج عرض سعر جاهز للإرسال للعميل.

---

## ١. تفعيل الصفحة (خطوة واحدة)

الصفحة معطّلة حتى تُضبط كلمة المرور. من لوحة Netlify:

**Site settings → Environment variables → Add a variable**

| المتغير | القيمة | إلزامي |
|---|---|---|
| `PRICING_ADMIN_PASSWORD` | كلمة مرور قوية من اختيارك | ✅ نعم |
| `PRICING_ADMIN_SECRET` | نص عشوائي طويل لتوقيع الجلسات | اختياري |

ثم أعد نشر الموقع (Deploys → Trigger deploy) حتى تقرأ الدوال المتغير الجديد.

**ملاحظات مهمة:**

- كلمة المرور تبقى على خادم Netlify ولا تصل متصفح المشرف إطلاقاً. التحقق يتم
  في الدالة `pricing-login`، والمتصفح يستلم توكن جلسة موقّعاً صالحاً **١٢ ساعة**.
- إن لم تضبط `PRICING_ADMIN_SECRET` فسرّ التوقيع يُشتق من كلمة المرور نفسها.
  النتيجة: **تغيير كلمة المرور يُنهي كل الجلسات المفتوحة فوراً** — وهذا مفيد لو
  ترك أحد الموظفين العمل.
- اختر كلمة مرور طويلة. الحماية الفعلية هي قوة كلمة المرور؛ الصفحة تُبطئ
  التخمين (٨ محاولات خاطئة لكل عنوان IP خلال ١٠ دقائق) لكنها لا تمنعه بديلاً عن
  كلمة مرور جيدة.
- المسار `/admin/` محجوب أصلاً في `public/robots.txt`، والصفحة تُرسل
  `noindex, nofollow` — فلن تظهر في نتائج البحث.

## ٢. تعديل الأسعار

كل الأسعار والمعاملات في ملف واحد:

```
netlify/lib/pricing-rates.mjs
```

عدّل القيم ثم ادفع التغيير (`git push`) ليُعاد نشر الموقع. حدّث كذلك حقل
`version` في أعلى الملف حتى يظهر للمشرف أنه يعمل على التسعيرة الأحدث (يظهر
الرقم في شريط الصفحة العلوي).

### لماذا الأسعار في مجلد `netlify/` وليس في `src/`؟

أي ملف داخل `src/` يُحزَم مع ملفات الموقع العامة، ويقدر أي زائر يفتح ملف
الجافاسكربت ويقرأ أسعارك وتكاليفك وهوامش ربحك. الملف هنا يبقى على الخادم، ولا
تُرسل محتوياته إلا بعد نجاح تسجيل الدخول.

### ما الذي يمكن تعديله

| القسم | الوصف |
|---|---|
| `vatRate` | نسبة ضريبة القيمة المضافة (٠٫١٥) |
| `minCharge` | الحد الأدنى لقيمة أي عملية قبل الخصم والضريبة |
| `depositPercent` | نسبة العربون من الإجمالي النهائي |
| `propertyTypes` | أنواع العقارات: سعر الأساس، رسوم الدور الإضافي، وشرائح سعر المتر |
| `rooms` | سعر كل نوع غرفة |
| `conditions` | معامل حالة الغرفة (نظيف / متوسط / عميق) |
| `serviceTypes` | معامل نوع الخدمة + إنتاجية العامل لاقتراح الساعات |
| `urgencies` | معامل الاستعجال |
| `extras` | الإضافات (مكيفات، كنب، سجاد، مسبح…) |
| `cost` | أجر الساعة، النقل، نسبة المواد، أقل هامش ربح مقبول |

### شرائح سعر المتر

`areaTiers` تعمل بشرائح تصاعدية مثل شرائح الضريبة: أول ٢٠٠ م² بسعر الشريحة
الأولى، والزيادة عليها بسعر الشريحة الثانية، وهكذا. هذا يمنع القفزة المفاجئة في
السعر عند حدود الشرائح. الشريحة الأخيرة تُكتب بـ `upTo: null` (بلا حد أعلى).

مثال — فيلا ٣٠٠ م²: أول ٢٠٠ × ٤٫٥ + الـ ١٠٠ التالية × ٣٫٥ = **١٬٢٥٠ ر.س**.

## ٣. كيف تُحسب النتيجة

```
سعر أساس نوع العقار
+ تكلفة المساحة بالشرائح
+ (عدد الأدوار − ١) × رسوم الدور
+ لكل غرفة: السعر × الكمية × معامل الحالة
+ الإضافات: السعر × الكمية
─────────────────────────────
× معامل نوع الخدمة
× معامل الاستعجال
─────────────────────────────
⇒ يُرفع للحد الأدنى إن كان أقل منه
− الخصم (نسبة أو مبلغ)
= الصافي قبل الضريبة
+ ضريبة القيمة المضافة
= الإجمالي النهائي  ←  ومنه يُحسب العربون
```

**الحد الأدنى يُطبَّق قبل الخصم** عن قصد: قيمة العمل لا تنزل تحت الحد تلقائياً،
لكن يبقى بيد المشرف أن ينزل تحته بخصم مقصود يظهر واضحاً في التفصيل.

### مؤشر الربحية

يُدخل المشرف عدد العمال والساعات (الصفحة تقترح الساعات من المساحة وإنتاجية
الخدمة، ويقدر يعدّلها):

```
التكلفة = (عدد العمال × الساعات × أجر الساعة) + النقل + (الصافي × نسبة المواد)
الربح   = الصافي قبل الضريبة − التكلفة
الهامش  = الربح ÷ الصافي قبل الضريبة
```

الضريبة لا تدخل في حساب الهامش لأنها ليست إيراداً للشركة. إذا نزل الهامش تحت
`minMarginPercent` تتحول البطاقة إلى الأحمر مع تنبيه قبل إرسال العرض.

## ٤. المخرجات

| الزر | المحتوى |
|---|---|
| **إرسال العرض واتساب** | يفتح محادثة واتساب مع رقم العميل ونص العرض جاهزاً |
| **نسخ عرض العميل** | نفس النص للنسخ واللصق في أي قناة |
| **نسخ الملخص الداخلي** | العرض + التكلفة والربح والهامش — **لا يُرسل للعميل** |

خانة **«إظهار تفصيل البنود للعميل»** تتحكم في ظهور بنود الغرف والإضافات داخل
عرض العميل. نص العرض لا يحتوي أي رقم داخلي في الحالتين — لا أجور ولا تكاليف ولا
هوامش.

رقم جوال العميل يُقبل بأي صيغة (`05xxxxxxxx` أو `5xxxxxxxx` أو `966…`) ويُحوّل
تلقائياً لصيغة واتساب الدولية.

## ٦. حل المشكلات

**«الصفحة غير مهيأة بعد»** — متغير `PRICING_ADMIN_PASSWORD` غير موجود، أو
أُضيف بدون إعادة نشر. أضفه ثم أعد النشر.

**تسجيل الخروج تلقائياً** — الجلسة صالحة ١٢ ساعة، وتنتهي أيضاً عند تغيير كلمة
المرور أو إغلاق تبويب المتصفح (التوكن يُحفظ في `sessionStorage` وليس دائماً).

**«محاولات كثيرة خاطئة»** — ٨ محاولات فاشلة خلال ١٠ دقائق. انتظر انتهاء المدة.
