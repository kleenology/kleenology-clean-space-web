# برنامج الشركاء — المقاولون والشركات اللي يحيلون عملاء

عمولة **10٪ من قيمة أول طلب** لكل عميل محال (بعد الخصم وقبل الضريبة)، تُصرف
بعد سداد العميل بكشف شهري على الواتس.

## الروابط

| الرابط | لمن |
|---|---|
| `kleenology.me/partners` | المقاول: طلب الانضمام، وتسجيل عميل بالكود |
| `kleenology.me/p/P-XXXXX` | العميل: رابط الشريك الخاص — يسجّل بياناته أو يحجز واتساب والكود في الرسالة |
| `kleenology.me/admin/pricing` ← **الشركاء** | الإدارة |

## دورة العمل

1. المقاول يسجّل من `/partners` ← يظهر في **طلبات انضمام**.
2. **اعتماد** ← يفتح واتساب برسالة فيها كوده ورابطه.
3. العملاء يوصلون من نموذج الشريك أو رابطه، أو تضيفهم يدوياً (عميل حجز واتساب وذكر الكود).
4. تحرّك حالة العميل: `جديد ← تم التسعير ← تم التنفيذ ← العميل دفع`، وتكتب **قيمة الطلب قبل الضريبة**
   (أسعار الكتالوج شاملة الضريبة: اقسم على 1.15).
5. آخر الشهر: **الكشف** عند الشريك ← **إرسال الكشف واتساب** ← حوّل المبلغ ←
   **تم التحويل — علّمها مدفوعة**.

## الاستبعاد التلقائي (أول طلب فقط)

لحظة تسجيل العميل يُفحص جواله: إن سبق أن أحاله شريك، أو له معاينة أو فحص جودة
محفوظ، يُعلَّم **غير مؤهل** مع السبب. تقدر تغيّر الأهلية يدوياً. الكشف يذكر
للشريك أن العميل «مسجّل لدينا قبل الإحالة» بلا تفاصيل.

| `src/pages/PartnerReferral.tsx` | صفحة رابط الشريك |
| `src/components/pricing/PartnersPanel.tsx` | تبويب الإدارة |
