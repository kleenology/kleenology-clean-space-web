# برنامج الشركاء — المقاولون والشركات اللي يحيلون عملاء

عمولة **10٪ من قيمة كل طلب لكل عميل محال** (بعد الخصم وقبل الضريبة)، بلا
استبعاد ولا حد لعدد الطلبات. تُصرف بعد سداد العميل بكشف شهري على الواتس.

## الروابط

| الرابط | لمن |
|---|---|
| `kleenology.me/partners` | المقاول: طلب الانضمام، وتسجيل عميل بالكود |
| `kleenology.me/p/P-XXXXX` | العميل: رابط الشريك الخاص — يسجّل بياناته أو يحجز واتساب والكود في الرسالة |
| `kleenology.me/partners` ← **حسابي** | الشريك: عملاؤه وعمولاته، وباركود رابطه ورسالة جاهزة للنشر (يدخل بكوده وجواله المسجّل) |
| `kleenology.me/admin/pricing` ← **الشركاء** | الإدارة — رقم أحمر بعدد العملاء الجدد |

## خصم العميل المحال

العميل اللي يجي عن طريق شريك ياخذ **خصم 10٪ على أول طلب**. يظهر له في صفحة رابط
الشريك ورسالة الواتس، ويُحفظ مع العميل (`customerDiscount`) ويظهر في لوحة الإدارة
حتى يُطبَّق قبل كتابة المبلغ. النسبة في `CUSTOMER_DISCOUNT_PERCENT`
(`netlify/lib/partners.mjs` و`src/lib/partners/api.ts`).

## دورة العمل

1. المقاول يسجّل من `/partners` ← يظهر في **طلبات انضمام**.
2. **اعتماد** ← يفتح واتساب برسالة فيها كوده ورابطه.
3. العملاء يوصلون من نموذج الشريك أو رابطه، أو تضيفهم يدوياً (عميل حجز واتساب وذكر الكود).
4. حالة العميل: `جديد ← تم التسعير ← عميل فعّال` (أو `ما تم`).
5. **كل ما دفع العميل طلباً** تكتب مبلغه قبل الضريبة وتضغط **طلب مدفوع**
   (أسعار الكتالوج شاملة الضريبة: اقسم على 1.15). كل طلب له عمولته.
6. آخر الشهر: **الكشف** عند الشريك ← **إرسال الكشف واتساب** ← حوّل المبلغ ←
   **تم التحويل — علّمها مدفوعة**.

## بلا استبعاد

كل عميل يحيله الشريك يُحسب، حتى لو تعامل معنا قبل. إذا سجّل شريكان نفس العميل
يظهر تنبيه «مسجّل أيضاً عند…» — للعلم فقط، حتى لا يُضاف نفس الطلب عند الاثنين.
خانة **يستحق عمولة** تُلغى يدوياً لعميل وهمي أو إحالة غير صحيحة.

الطلب اللي صُرفت عمولته ما يُحذف، حتى تبقى الكشوف السابقة صحيحة.
